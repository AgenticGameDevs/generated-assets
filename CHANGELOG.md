# Changelog

## 0.3.0

- Curated starter packs make the Travellers, humanoid motion, procedural scenery and sounds easy to find.
- Select assets, share the selection, or download a ZIP with verified files, full metadata, credits and a revision-pinned lockfile.
- Portable CLI lock/restore support preserves exact downloads, validates library URLs and protects existing files.
- Rig relationships, file-size filtering, animation scrubbing, playback speed, wireframe and reduced-motion support improve inspection.
- A GLB converter provides decoded geometry and PNG textures for importers without Meshopt/WebP support. Traveller 1 imports were checked in Blender 5.2.1 LTS and Godot 4.7.1 with 24 bones and nine clips retained.
- Added integration/API/maintenance documentation, a runnable Three.js example, native import-check scripts, MCP pack/lock tools, Khronos validation, browser tests and dependency update proposals.

## 0.2.0

- Published 172 assets with individual descriptions, tags, source descriptors, licenses, technical metadata and checksums.
- Included both Traveller character models after reference ownership confirmation, plus a standalone rig, nine individual clips and their combined pack.
- Added contribution/governance guidance, agent skills, local stdio MCP and validated GitHub Pages deployment.

## 0.1.0

- Initial Fjordfall and SKYBOUND gallery, generation workflows, source recipes and media licensing records.
